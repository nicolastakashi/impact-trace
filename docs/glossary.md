# Glossary

One word per thing, the same in the UI, the code, the API and these docs.
Names in code use these words in full: `withoutMe`, not `wm`; `keyResult`, not `kr`.

| Word | What it is | Not |
|---|---|---|
| event | One fact a collector found: a PR merged, an issue done, a Slack message, a meeting, a doc | item, evt |
| thread | Events that belong to one piece of work, in one week | item, group |
| week | An ISO week, `2026-W43` | w, wk |
| project | A Linear project, or a topic you made | group, s |
| topic | A project you made yourself, not from Linear | |
| label | Claude's or your value for one field of a thread: title, summary, mode, pillar, without me, discard | |
| review | You decide each thread's labels; Claude suggests | |
| discard | Your "not impact" decision on a thread; keeping it is the opposite | |
| mode | How the thread made an impact: clarify, prevent, solve, build, elevate, external | |
| pillar | big-picture, execution or leveling-up | |
| without me | Your answer: would it have happened without you | wm |
| goal | An objective you wrote, team or personal | objective, g |
| key result | A goal's measurable result | kr |
| check-in | Your weekly confidence in a goal, 1 to 10 | |
| milestone | A Linear project milestone | ms |
| mention | A Slack message that names you | |
| praise | A mention or review comment that thanks you | rec, recognition |
| ask | A mention that asks you for something | |
| feedback | Claude's weekly read of how you write: patterns, a strength, an experiment | fb |
| feedback piece | One pattern, the strength or the experiment: what you accept or reject | item |
| span | A thread, drawn on Trace | |
| trace | A week, drawn on Trace | |
| sample | The fictional example data shown before your first review | |

Well-known short words stay: `id`, `url`, `api`, `db`, `json`, `html`, `pr`, `css`, and `cn`
(the shadcn class-name helper).
